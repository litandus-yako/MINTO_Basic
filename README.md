# MINTO Basic (ミント ベーシック)
A lightweight visual catalog & viewer for hyperspectral data

本ソフトウェア『MINTO Basic』は、研究者や技術者が手元の膨大なハイパースペクトル画像データをパッと見渡して、直感的に閲覧・整理するための軽量なデスクトップアプリケーションです。
散らかりがちなハイパースペクトルデータを「ちゃんと見んと（見ないと）」という思いから、見やすいサムネイルの一覧表示と快適なファイル管理を実現するツールとして開発されています。

---

## 主な機能

* ENVIフォーマットの自動スキャンとカタログ化
  * 指定したフォルダ配下のヘッダーファイル (`.hdr`) を自動探索し、メタデータ（解像度・波長域・バンド数など）をデータベースへ自動登録。
* サムネイル画像の一覧表示とRGB波長カスタマイズ
  * 多バンドデータから代表的な波長（R/G/B）を抽出し、サムネイル画像を自動生成。RGB波長の割り当て変更にも対応。
* 直感的な検索・フィルタリング
  * ファイル名、被写体名、メモ内容によるキーワード検索や、★お気に入りデータのみの絞り込み表示が可能。
* メタデータ・属性情報の確認と入力
  * 各データを選択するだけで詳細な画像情報を確認。手動での「被写体」ラベルや「メモ」の入力・保存に対応。

---

## 動作環境

* 対応OS: Windows 10 / 11 (64-bit)
* メモリ: 8 GB 以上推奨 (扱うハイパースペクトルデータのサイズに依存します)
* ディスプレイ解像度: 
  - 必須: 1280 × 720 (HD) 以上
  - 推奨: 1920 × 1080 (フルHD) 以上
  ※ サムネイル一覧テーブルと詳細情報パネルを同時に表示するため、フルHD以上のモニターでの使用を推奨します。

## インストール手順

1. リポジトリ（ https://github.com/litandus-yako/MINTO_Basic ）より最新の `MINTO_Basic_**.msi` をダウンロードします。
2. ダウンロードした `.msi` ファイルをダブルクリックしてインストーラーを起動します。Microsoft Defenderの警告が表示された場合は、[詳細情報] → [実行] で回避してください（自己責任）。
3. 画面の指示に従ってインストールを完了させてください。
4. インストール完了後、デスクトップに作成される「MINTO Basic」アイコン、またはインストール先フォルダ内のexeファイルから起動できます。

## 基本的な使い方

1. 検索フォルダの指定
   * ウインドウ左上の [📂 検索フォルダ設定] ボタンより、ハイパースペクトルデータ（`.hdr`）が格納されているフォルダを選択します。自動的にバックグラウンドスキャンが開始され、データが一覧表示されます。
2. データの閲覧と検索
   * ウインドウ右上の検索バーからキーワードを入力してデータを絞り込んだり、[★ のみ] チェックボックスでお気に入りデータのみを抽出できます。
3. 詳細情報の入力
   * 一覧からデータを選択すると、ウインドウ左下の詳細パネルに高解像度サムネイルと画像メタデータが表示されます。「被写体」や「メモ」の入力欄から任意のテキストを記録できます。
4. フォルダを開く
   * テーブル上の [📁 開く] ボタン、または行をダブルクリックすることで、対象データが保存されているエクスプローラーを直接開くことができます。

## 高度な機能が必要な方へ（MINTO Proのご案内）

`MINTO Basic` は、軽量・高速なビューアおよび基本的なデータ整理機能に特化しています（今後のアップデート予定はありません）。
AIによる自動分類や大量データの一括編集、カスタムラベルの自由な追加機能が必要な方は、有料版の `MINTO Pro` （現在開発中）をご検討ください。

【MINTO Pro に搭載予定の主な機能】
* 機械学習/ディープラーニング（ResNet18 / SVM / ランダムフォレスト / k-means）による被写体のAI自動分類
* 分類モデル（`.pkl`）の保存・読み込みおよびプロジェクト間共有
* 共通・個別カスタムラベル（属性フィールド）の自由な追加・削除
* 複数データに対する「お気に入り」「被写体ラベル」「AI推定結果」の一括編集（Bulk操作）
